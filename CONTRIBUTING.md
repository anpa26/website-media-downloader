# Contributing

Thank you for your interest in contributing to this project! Bug reports, feature requests, and pull requests are welcome.

## Reporting Bugs

If you encounter a bug, please download and install the `-debug-` version of the extension and download the logs by following these steps:

1. Open **Settings → Advance Settings**.
2. Scroll down and click **Download Log**.
3. Attach the downloaded log to your GitHub Issue.

Please remove any sensitive information from logs before uploading them.

## GitHub Issues

GitHub Issues is the only accepted channel for bug reports, feature requests, and other project-related concerns.

- Check existing issues before opening a new one.
- Keep reports clear and relevant to the project.
- Multiple unrelated issues may be combined into a single issue only with prior permission from the maintainers.
- Be respectful and constructive in all discussions.

## Pull Requests

For significant changes, such as new features, major refactors, or architectural modifications, please open an issue and obtain feedback from the maintainers before starting work.

When submitting a pull request:

- Clearly describe the changes and their purpose.
- Reference related issues when applicable.
- Keep changes focused and avoid unrelated modifications.
- Include relevant tests or documentation updates when necessary.
- Address review feedback constructively.

Submitting a pull request does not guarantee acceptance. Maintainers reserve the right to request changes, accept, or reject contributions.
